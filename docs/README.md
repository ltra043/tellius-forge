# Documentation

User-oriented guides for modifying FE9/FE10 assets with Tellius Forge.

The written guides are intended to supplement the tutorial videos and serve as a reference while working.

## Quick-Start Guide

1. Read [Getting Started](./getting-started.md)
2. Watch the [tutorial videos](https://youtube.com/playlist?list=PL650N9tNdfYazuxS5b63BzaUKxZLErT0e&si=egK1UIZA0K-ZWOmL).
3. Install the Blender plugin.
4. Import models and experiment in Blender.
5. Follow [Body & Skeleton Workflow](./body-skeleton-workflow.md) when modifying models.
6. Read [Animation Workflow](./animation-workflow.md) if you plan to modify animations.
7. Reference other documents as needed

Types:
- <b>Fundamental:</b> Instructional guides that cover foundational processes and core workflows.
- <b>Advanced:</b> Instuctional guides that cover more advanced topics. These walk through optional modifications that are not aboslutely necessary to learn. 
- <b>Reference:</b> Meant to be read as needed and may be referenced by multiple other documents

Naming Conventions:
- `*Workflow*`: guides that teach a core workflow. These may cover a broad range of modifications or teach skills that can be applied to a variety of scenarios.
- `*Edits*`: More targeted and narrow in scope.
  - May be classified as **Fundamental** if they describe modifications that are considered essential learning or commonly needed.
  - May be classified as **Advanced** if they are more difficult, niche, or less necessary. They may still be desired, but are not absolutely imperative for game function.
